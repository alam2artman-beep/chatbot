# سایت شخصی — محمد فضلی / Mohammad Fazli

Portfolio دوزبانه (فارسی RTL + انگلیسی LTR) با تم تیره و پالت رنگی **آبی، قرمز و سبز نعنایی**.

## اجرا
فایل `index.html` را مستقیم در مرورگر باز کنید، یا با سرور محلی:

```bash
python server.py 8080
```

سپس به `http://localhost:8080` بروید.

## ساختار
```
index.html          صفحه اصلی (ساختار + محتوای دوزبانه)
assets/css/style.css استایل‌ها، پالت رنگ، RTL/LTR، انیمیشن‌ها
assets/js/main.js   سوییچ زبان، تایپینگ، اسکرول ریویل، شمارنده‌ها، فرم
assets/fonts/       وزیرمتن (Light/Regular/Medium/Bold) + Bebas Neue
assets/img/         عکس پروفایل
```

## ویژگی‌ها
- **دوزبانه**: سوییچ FA/EN با ذخیره در localStorage و تغییر خودکار جهت (RTL/LTR). فارسی با فونت وزیرمتن.
- **بخش‌ها**: هیرو (عکس + افکت تایپینگ)، درباره + شمارنده‌ها، مهارت‌ها (نوار پیشرفت)، تجربه (تایم‌لاین)، گواهینامه‌ها، تحصیلات، تماس.
- **انیمیشن**: Reveal-on-scroll با IntersectionObserver، نوارهای متحرک، شمارنده‌های عددی، افکت تایپینگ، orb‌های نورانی.
- **ریسپانسیو** و پشتیبانی از `prefers-reduced-motion`.

## فرم تماس
فرم به‌صورت فرانت‌اند است (بدون بک‌اند). برای فعال‌سازی واقعی، در `main.js` بخش `CONTACT FORM SUBMISSION` را به یک endpoint واقعی وصل کنید.
**هیچ توکن یا رمز عبوری در کلاینت هاردکد نشده است.**
